Continuum Robot Modeling with Action Conditioned Flow Matching

Abstract (English): Predicting the shape of tendon driven continuum robots (TDCRs) at steady state from actuation remains challenging due to continuous deformation, complex tendon routing, compliance, friction, and fabrication variability. In this paper, we address this problem as kinematic self modeling conditioned on action. We present a lightweight 3D printed TDCR hardware platform and an RGB-D data collection pipeline with multiple cameras, and we learn a point cloud flow matching model that maps motor actuation states to the robot's settled 3D geometry. The model is trained from randomly sampled quasi static configurations and evaluated on test motor commands within the same TDCR design family and actuation range. We compare against prior 3D deformable object and robot self modeling approaches in both MuJoCo simulation and real hardware experiments. Experiments on simulated 2-, 3-, and 5-module TDCRs and real 2- and 3-module robots show improved shape prediction accuracy under CD and EMD metrics. We further show in simulation that the same conditional formulation generalizes to tip payload as a conditioning input, enabling payload conditioned steady-state shape prediction. These results demonstrate a data driven self modeling framework for quasi static TDCR geometry prediction.

摘要（中文）: 摘要： 由于连续变形、复杂的肌腱路径、柔顺性、摩擦和制造差异性，从驱动状态预测肌腱驱动连续体机器人（TDCR）的稳态形状仍具挑战性。本文将该问题视为基于动作的机器人运动学自建模。我们提出了一种轻量化的3D打印TDCR硬件平台和基于多摄像头的RGB-D数据采集流程，并学习了一种点云流匹配模型，该模型将电机驱动状态映射至机器人的稳定三维几何形态。模型通过随机采样的准静态构型进行训练，并在相同TDCR设计族系和驱动范围内的测试电机指令上进行评估。我们在MuJoCo仿真和真实硬件实验中，与现有的三维可变形物体及机器人自建模方法进行了对比。在仿真中的2单元、3单元、5单元TDCR以及真实的2单元和3单元机器人上的实验表明，该方法在CD和EMD指标下提高了形状预测精度。我们进一步在仿真中证明，相同的条件建模框架可扩展至以末端负载为条件输入，实现负载条件下的稳态形状预测。这些结果展示了一种用于准静态TDCR几何预测的数据驱动自建模框架。

TLDR: The paper introduces a data-driven method using action-conditioned flow matching to predict the steady-state 3D shape of tendon-driven continuum robots (TDCRs) from motor actuation commands. It demonstrates improved accuracy over prior methods and shows the model can also condition on tip payload for shape prediction.
