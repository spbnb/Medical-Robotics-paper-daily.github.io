Towards Fully Automated Medical Imaging Code Generation via Validation-based Context Engineering

Abstract (English): Large language models (LLMs) have demonstrated considerable promise in program generation for small-scale and conventional application development; however, they remain limited when applied to complex, domain-specific tasks such as medical image processing. General-purpose models lack explicit domain knowledge and robust validation mechanisms to ensure correctness, often requiring substantial human intervention to produce reliable processing pipelines. To address these limitations, we propose AutoMedImg, a multi-agent framework for fully automated medical image processing code generation. AutoMedImg orchestrates specialised agents across two phases: a Planning Phase that performs dataset analysis and architecture design with semantic and formal verification, and a Coding Phase that generates modules in parallel with static checking, execution testing, and assembly validation. This multi-stage validation mitigates error propagation throughout generation, while comprehensive auto-context engineering combining domain-specific knowledge bases, shared memory, and validation feedback automates context construction without manual prompting. A cross-project adaptive pipeline synthesis mechanism further accumulates validated pipelines and retrieves proven components for new tasks based on project similarity, enhancing generation efficiency through cross-project learning. Extensive evaluation across six diverse and well-established medical imaging datasets with five backbone LLMs demonstrates that AutoMedImg achieves zero human intervention, with Dice scores of up to 0.90 for segmentation tasks and 99% accuracy for classification.

摘要（中文）: 摘要： 大型语言模型（LLM）在面向小型及常规应用开发的程序生成中展现出显著潜力，但在处理医学图像处理等复杂领域特定任务时仍存在局限。通用模型缺乏显式的领域知识与确保正确性的稳健验证机制，往往需要大量人工干预才能生成可靠的处理流程。为突破这些限制，我们提出AutoMedImg——一个用于全自动医学图像处理代码生成的多智能体框架。AutoMedImg通过两个阶段协调专用智能体：规划阶段执行语义验证与形式化验证的数据集分析和架构设计，编码阶段并行生成模块，并辅以静态检查、执行测试与组装验证。这种多阶段验证机制可抑制生成过程中的错误传播；同时，结合领域知识库、共享内存与验证反馈的综合自动上下文工程，无需人工提示即可自动化上下文构建。跨项目自适应流程合成机制进一步累积已验证的流程，并基于项目相似性检索经过验证的组件用于新任务，通过跨项目学习提升生成效率。在六个多样化且成熟的医学影像数据集上，结合五种骨干LLM的广泛评估表明，AutoMedImg实现了零人工干预，分割任务的Dice得分高达0.90，分类任务准确率达99%。

TLDR: AutoMedImg is a multi-agent framework that uses validation-based context engineering to generate fully automated medical image processing code, achieving zero human intervention with high Dice scores and accuracy across multiple datasets.
